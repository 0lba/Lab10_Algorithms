Алгоритм - это точная конечная последовательность действий, направленная на достижение определённой цели или решение конкретной задачи.
## Как составляются блок-схемы
Порядок составления:
1. Определить входные и выходные данные
2. Разбить алгоритм на отдельные шаги
3. Подобрать фигуру для каждого шага
4. Соединить фигуры стрелками в порядке выполнения
5. Проверить логику: все ветви ведут к концу, нет тупиков
6. При необходимости добавить цикл
